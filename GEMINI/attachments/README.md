# attachments — ملفات تُرفع بيد صاحب المشروع

**الوكيل يجهّز ولا يرفع.** هذا المجلد يحوي نسخًا من الملفات التي ستُرفَق في AI Studio،
مع `manifest.json` يوضّح كل ملف: ما هو، ومن أي أصل أُخذ، وبصمته.

## القاعدة

1. الوكيل ينسخ الملف هنا ويحدّث `manifest.json` (المصدر + `sha256` + سبب الاختيار).
2. يخبر صاحب المشروع بالاسم الدقيق للملف والمجلد.
3. صاحب المشروع يرفعه بنفسه (زر الإرفاق → Upload files، أو سحب الملف).
4. بعد الرفع، الوكيل يتحقق من ظهور المرفق في الصفحة (`python3 GEMINI/studio.py attachments`).

## لماذا نسخة لا رابط

نافذة اختيار الملفات تتعامل مع مسارات حقيقية؛ النسخة تجعل المسار قصيرًا وواضحًا،
وتمنع أي لمس للأصول في `HAPPY_ACCIDENT_MATERIALS/`.

## التنظيم المقترح

```
attachments/
  round01/
    blind_a.mp3        # المقطع الأول، بلا أي دلالة في الاسم
    blind_b.mp3
  manifest.json
```

الأسماء في الجولة العمياء **محايدة**: لا `hac`، لا `01`، لا `attempt`، لا اسم أغنية.
