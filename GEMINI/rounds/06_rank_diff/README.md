# الجولة 06 — ترتيب الفروق (أداء المغني × المزيج)

**الوحدة:** ملفان كاملان، بلا قصّ — نسخ الجولة 01 نفسها (`attachments/round01/A.mp3` · `B.mp3`).
**المادة:** A = `TRACK_01` (HAC، تقييم 10) · B = `hat_01_cl_g10_1117111` (تقييم 7.5).
**السؤال:** خمسة فروق مرتّبة بالأثر + موضع زمني لكل فرق + «لا فرق» صريح + سؤال سلبي (عدد أصوات المغني).

## لماذا الجولة هذه موجودة

الجولة 01 سألت «صف ثم قارن» بنفس الملفين، فسقط 3 من 5 ادعاءات صوتية (#24 · #25 · #26)
والتصق الواصف بالسرد الزمني. الجولة 02 نجحت عندما صار السؤال عن **فعل صوتي محدد** في مقطع قصير.
هذه الجولة تختبر المادة نفسها بسؤال **ترتيب** بدل وصف: هل يستخرج أهم الفروق، أم يسرد؟

**الحدّ المعلن مسبقًا:** لا نسخة مكرّرة، ولا مقاطع متحاذية ⇒ لا تحكم على «التركيب» بل على «الترتيب والقابلية للفحص» فقط.
